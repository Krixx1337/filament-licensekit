# Security policy

LicenseKit is pre-release software. Security fixes target the latest alpha release
and the `main` branch. Update to the latest alpha or `main` commit before reporting
a problem.

Report vulnerabilities privately through [GitHub security advisories](https://github.com/Krixx1337/filament-licensekit/security/advisories/new).
Include the affected commit, PHP and Laravel versions, reproduction steps, and the
potential impact. Do not publish license keys, API tokens, customer data, or exploit
details in public issues.
